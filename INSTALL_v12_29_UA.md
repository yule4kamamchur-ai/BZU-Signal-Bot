# v12.29 Pro Quant

1. Розпакуйте компактний ZIP. Завантажте файли **всередині** `01_UPLOAD_TO_REPO_ROOT` у корінь наявного репозиторію. Натисніть **Commit changes**.
2. Завантажте `main.yml` з `02_UPLOAD_TO_WORKFLOWS` у **.github/workflows**. Натисніть **Commit changes**. Кореневий `WORKFLOW_main.yml` є копією для звірки.
3. Після обох комітів запустіть **Actions → Run workflow**. Дочекайтеся успішного **deploy-pages**, відкрийте сайт через **Settings → Pages → Visit site** й натисніть **⌘Shift+R**.

Завантажуйте файли з обох папок за відповідними шляхами. Поточний журнал і `live_state.json` оновить наступний цикл GitHub Actions. Повний архів призначений для локальної роботи.

## Допуск і рівні

- Самостійні зони формуються на 15m, 1H або 4H. Мікрозони 3m відсіюються, а 3m залишаються джерелом підтвердження й аудиту. `SESSION_MEAN_RECLAIM` вимкнено для нових ліміток.
- Мінімальна ширина зони дорівнює одному тику. Закрита свічка, яка досягла 60% глибини зони після її формування, списує зону. У діапазоні відстань до найближчої межі має становити щонайменше 0.15 ATR15.
- Структурна відстань до стопа враховує буфер 0.25 ATR15. Мінімальний ризик дорівнює 0.40 ATR15 у межах $0.22–$0.28. Максимум становить $0.65. Округлення враховує крок ціни. Якщо за цього максимуму стоп опиняється всередині структурної межі, допуск закрито.
- TP1 використовує перший доступний рівень від 1.40R після відступу на один тик або проєкцію 1.50R. Для допуску TP2 потрібен наступний структурний рівень від 2.20R та достатній чистий R:R після комісій. Непройдені структурні перешкоди блокують план. Розрахунковий TP2 може залишатися в довідковому рядку.
- План на радарі має бал від 60, TP1 від 1.40R, відповідність напрямку та фінальний допуск. Базове вікно дистанції допускає відкат до $0.60 навіть при малому ATR. Інші перевірки рушія застосовуються далі. На графіку один робочий план має три лінії, а за його відсутності видно до двох незалежних структурних смуг.

Паперові ордери й позиції, що вже є в журналі, продовжують супровід за збереженими умовами.

## Банер

Локальна реакція M5 відображається у своєму моніторі. Вона потребує підтвердження фактичного входу.

## Перевірка

Пройшли 91 штатний Python-тест, синтаксична перевірка JS та сценарії інтерфейсу із синтетичним DOM. У цьому середовищі запуск Chromium заблоковано системним обмеженням сокетів, тому візуальний рендеринг не перевірено. Офлайнова перевірка зліпка з архіву відсіяла обидві зони 3m. Результат перевірки зліпка не використовується як оцінка прибутковості.
