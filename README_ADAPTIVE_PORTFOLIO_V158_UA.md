## Що працює

1. M1/M5 Active Engine v15.5: сім активів, усі 9 сімейств аналізуються, 7 сімейств у PAPER, 2 у Shadow. Ранній M1 (за налаштуванням) та дві останні M5, незалежні LONG/SHORT, короткий Retest, Momentum v15.4, Early Structure Shift, beta-relative, роздільні витрати, окреме rolling-навчання і Shadow. Його торгові рішення й чинні ризикові множники не змінені.
2. H1 `PEAK_CURRENT`: Donchian 30 попередніх закритих годин, SL 2.5 ATR(14) актуальної H1, трейл 3.5 ATR від екстремуму позиції, без фіксованого TP. Стоп оновлюється тільки після закриття H1, не застосовується до старих свічок. Вхід за актуальною котировкою, сигнал не старший 15 хв, відстань до сигнального закриття не більше 0.5 ATR у напрямку угоди. Захист від застарілих даних і дублів.
3. H1 `CLOSE_PRIOR`: незалежний порівняльний PAPER-рахунок. Початковий ATR і ATR трейлінгу за попередню H1, трейл від закриття H1. Не є копією оригінального ідеалізованого 180-денного скрипта: збережено реалістичніші правила входу, ризику й виконання.
4. `MIXED_PEAK_RANGE`: один дослідницький рахунок зі спільним бюджетом для H1 Peak та M15 Mean Reversion Reclaim. M15: 20 попередніх закритих M15, межі 2.2 стандартного відхилення, повернення за межу після свіпа, ціль — попереднє середнє; стоп за свінгом з буфером 0.25 ATR або щонайменше 1.6 ATR. Початкове дослідницьке співвідношення чистої цілі до оціненого збитку не нижче 1.25. Динамічний показник ефективності руху впливає на рейтинг, не блокує напрямок. Одна позиція на символ; при одночасних кандидатах того самого символу перевага H1, інакше M15; загальний ризик розподіляється між кандидатами. Це гіпотеза, а не оптимізовані чи доведені правила.
5. `RANGE_ONLY`: доступний у replay для незалежної оцінки внеску M15; не окремий live-рахунок.
6. Shadow геометрії для нових MARKET-позицій M1/M5: STATIC_CONTROL, SL_150, SL_TP_150, TP_150. Однаковий момент входу, горизонт 18 год, статичні бар'єри, порівняння лише повних спостережених пар, без funding. Не змінює фактичний журнал або метамодель.
7. Збережено наявний worker (60 секунд на постійному сервері), планувальник GitHub та інтервал 180 секунд за замовчуванням. Для worker потрібен окремий завжди увімкнений Linux/Docker-хост і міграція актуального журналу, а GitHub як writer має бути вимкнений через `BZU_SERVER_MODE=WORKER`. Не запускайте два незалежні writer для одного журналу. Сам worker цим патчем не розгортається.

## Ризик і рахунки

M1/M5 і три дослідницькі моделі — незалежні умовні PAPER-рахунки. Їхні результати НЕ можна сумувати як результат одного депозиту 100 USDT. Для кожної H1/змішаної моделі окремо: початкові 100 USDT, до 3% оціненого сумарного стоп-ризику з витратами, максимум 5x валового номіналу. Грубі кластерні ліміти ENERGY/METAL/CRYPTO (по третині бюджету, максимум половина крипто-кластера на нову криптопозицію), не оцінка повної коваріаційної матриці. Після збитку бюджет зменшується, прибуток не компаундується. Це не гарантія максимальної фактичної втрати при гепах, ліквідації чи прослизанні. Не збільшено ризик M1/M5, не створюються реальні біржові ордери. Єдиного портфеля для всіх трьох горизонтів M1/M5/H1/M15 ще немає: тільки H1+M15 у MIXED ділить капітал.
