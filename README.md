# BZU · v12.27 Direction Integrity & Live Reaction

Виправлено змішування напрямку, зони та SL між гілками матриці сетапів. У кандидати допускаються лише повні узгоджені плани з контекстним балом ≥65/100 і ціновим R:R TP1 ≥1.35.

[Встановлення, новий режим входу та межі перевірки](INSTALL_v12_27_UA.md).

У комплектному workflow увімкнено `BZU_ENTRY_MODE=LIVE_REACTION`: нові плани чекають спостереженої реакції у відкритій вкладці, без автоматичного створення паперової лімітки. Попередні ордери та позиції продовжують свій збережений цикл. Локальний сигнал браузера не створює біржову операцію та не записує ручне виконання в журнал.

```sh
python bot_oneshot.py --self-test
node --check live_terminal.js
node test_live_terminal_ui.cjs
```

Реакція за отриманими тиками відокремлена від підтвердження закритою свічкою M5. Часові розриви, невідомий підхід, пробій, прострочені дані або погіршення R:R блокують локальний вхід. Оцінки не є ймовірністю успіху; майбутній win rate цього режиму не встановлено.
