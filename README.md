# BZU · v12.28 Pro Quant Engine

Кожна валідна структурна зона отримує повний попередній план: Entry, SL, TP1, TP2, R:R та прозорий бал за п'ятьма критеріями. Радар показує найкращий доступний план за напрямком режиму; довідкові рівні мають явну причину обмеження. Попередній план не означає, що ордер уже виставлено.

[Встановлення компактного пакета, правила розрахунку та перевірки](INSTALL_v12_28_UA.md).

Комплектний workflow використовує `BZU_ENTRY_MODE=HYBRID`: лише фінально допущені рушієм плани класу A можуть створити паперову лімітку. Клас B+ чекає локального відбою M5 у відкритому дашборді. Браузер переобирає кандидатів за отриманою живою ціною та списує зону після спостереженого пробою SL, не змінюючи журнал виконання.

```sh
python bot_oneshot.py --self-test
node --check live_terminal.js
node test_live_terminal_ui.cjs
```

Перевірено: 83 штатні Python-тести та 46 сценаріїв UI із синтетичним DOM. Реальний рендеринг браузера не перевірено. Повний історичний набір має успадковані невдалі тести; точне порівняння наведено у `VALIDATION_v12_28.json` компактного пакета.

Котирування і M5 запитуються приблизно кожні 3 секунди. Реакція за отриманими тиками не є підтвердженням закритою M5; звук вмикається користувачем. Бали — евристична сума ознак, а не ймовірність прибутку. Дашборд не підключений до авторизованого торгового API та не відкриває біржових угод.
