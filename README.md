# BZU · v12.31 Market Wave

Сканер відбирає плани за закритими свічками. Зняття відомого екстремуму сесії з відбоєм або підтвердженим CHoCH дозволяє оцінити розворот, навіть якщо старший тренд ще зберігається. Імпульсний пробій відомого свінгу M15 тілом понад 0.60 ATR перемикає пріоритет напряму в поточному циклі.

Для продовження руху сканер перевіряє пробиті структурні зони, відкат 38.2–50% поточної хвилі, імпульсні блоки M5 та ретест пробою прапора. План допускається після перевірок структури, ризику, тейків і стану сигнального журналу. Для нового робочого ліміту діє відстань від $0.10 до меншого з $0.65 і 1.2 ATR M15. Для нового дзеркального рівня мінімальна відстань становить $0.20.

Обсяг формування понад 1.35 від середнього додає 6 балів. План за трендом на відстані $0.15–0.55 отримує ще 10. Біля підтвердженого нового екстремуму свіжий план продовження може використовувати проєкції 1.50R і 2.30R за відсутності відповідної ліквідності та за умови вільного шляху до цілей.

Банер і лінії графіка показують допущений близький план або чинну позицію. Далекі рівні залишаються резервом. Якщо котирування проходить TP1 до входу, браузер прибирає рівні цього плану. Фактичний стан ордерів і позицій відображається за журналом. Сканер виконується у GitHub Actions за наявним 15-хвилинним розкладом. Котирування і локальний відбір уже опублікованих планів оновлюються в браузері між циклами.

Для оновлення через GitHub завантажте файли з `01_UPLOAD_TO_REPO_ROOT` у корінь репозиторію, а `main.yml` із `02_UPLOAD_TO_WORKFLOWS` у `.github/workflows`. Запустіть **Actions → Run workflow** і дочекайтеся завдання `deploy-pages`.
