# BZU · v12.30 Institutional Pro

Банер і радар показують найближчий сценарій за трендом, глибший резерв та рівень протилежного напрямку. Кожна розрахована зона має бал, геометрію й умову допуску. Довідкові плани позначено окремо від робочих сигналів.

Зони оцінюються також під час торгів усередині діапазону. Рушій використовує ретест M15, відкат OTE та підтвердження закритою M5. Рішення зберігаються у сигнальному журналі.
