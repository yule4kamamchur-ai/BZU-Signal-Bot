# 24 сетапи: власні умови й ранній ліміт

Всі оригінальні детектори збережені. Кожен оцінюється на 15m, 1h і 4h; конкретний графік записується в `setup_timeframe`. Оригінальний детектор визначає, чи сформувався сетап. Сканер показує спостережувані умови ще під час формування.

| Сетап | Власні умови й рівень ліміту |
| --- | --- |
| SWEEP_RECLAIM | Зняття попереднього мінімуму, повернення закриття над рівень, сильне закриття; повторний прихід до знятого рівня. |
| CAPITULATION_RECOVERY | Два сплески обсягу й діапазону на молодшому графіку, відновлення над низом; ліміт на низі капітуляції. |
| RANGE_EDGE_REVERSAL | Режим RANGE/TRANSITION, достатня ширина, ціна біля краю; ліміт на межі. |
| FAILED_AUCTION_REJECTION | Вихід за день/тиждень/VWAP і повернення із хвостом відмови; ліміт на відкинутому рівні. |
| LIQUIDITY_SWEEP_REVERSAL_SHORT | Підтверджене зняття ліквідності над максимумом; SHORT на повторному підході. |
| BUYER_EXHAUSTION_SHORT | Попередня висхідна структура, стиснення тіл, слабша дельта або верхні хвости; зламаний рівень для SHORT-ретесту. |
| PULLBACK_CONTINUATION | Напрямок тренду, відповідний режим, достатня історія; EMA/VWAP/OB/FVG/свінг позаду ціни. |
| FRESH_BASE_CONTINUATION | Напрямок, сформована база та імпульс; ліміт на її робочій межі. |
| ACCEPTANCE_RETEST_CONTINUATION | Свіжий підтверджений пробій структури; ліміт на прийнятому рівні. |
| MOMENTUM_NO_PULLBACK_CONTINUATION | Імпульс і великий рух без відкату; неглибокий FVG або відкриття імпульсної свічки. |
| ACCELERATION_PULLBACK_REENTRY | Дві імпульсні ноги, відкат допустимої глибини; його край. |
| DIRECTION_FLIP_15M | Свіжа зміна структури основного графіка; зламаний свінг. Ідентифікатор збережено також для оцінок 1h/4h. |
| TREND_IGNITION | База до свічки пробою, закриття за межею та сильне тіло; ретест межі. |
| BREAKOUT_RETEST | Підтверджений пробій рівня попереднього дня/тижня; ретест. |
| RANGE_COMPRESSION_BREAKOUT | Оригінальна модель дуже щільної бази; вибір її робочої межі відносно середини. |
| OPENING_RANGE_BREAKOUT | Завершений реальний opening range, достатня ширина; межа для ретесту після проходу ціни. |
| LIQUIDITY_LADDER | Рівень ліквідності з кількома дотиками на допустимій відстані; ліміт на першій сходинці. |
| FAILED_OPENING_RANGE_BREAKOUT | Прокол OR й усі відповідні закриття всередині; повернення до невдалого пробою. |
| FAILED_BREAKOUT_SHORT | Знятий максимум, закриття нижче, відмова; SHORT-ретест. |
| MSS_REVERSAL_SHORT | Зміна структури вниз після попередньої ноги; зламаний свінг. |
| OR_FAILURE_2_SHORT | Дві чи більше невдалих спроб над OR-high; SHORT-ретест. |
| SESSION_MEAN_RECLAIM | Попередній відхід від VWAP; повернення на рівень вартості. |
| DAILY_WEEKLY_OPEN_RECLAIM | Попередній прохід через відкриття дня/тижня; повернення на цей рівень. |
| TIME_OF_DAY_ADAPTIVE | Завершений азійський діапазон, потрібна сесія й ціна біля межі; ліміт на цій межі. |

Готовність у % — частка пройдених власних умов патерну та перевірок допуску до ліміту, а не ймовірність прибутку. Неперевірені умови не зараховуються. Альтернативні сторони й рівні оцінюються окремо. 100% готовності означає, що перевірки геометрії та ризику вже пройдені; вільні місця й денні обмеження показуються окремо.

Для нового ліміту потрібні: визначений рівень та інвалідація, неперетин спреду, незастарілий і ще не відвіданий після виявлення рівень, мінімальний стоп 0.40% та волатильність, досяжна структурна ціль, достатній TP/SL без комісій. Відстань контролюється в ATR графіка сетапу. Підтверджений детектор дозволяє чекати майбутнього повернення ціни; універсальна повторна реакція 3m не вимагається. Непідтверджені умови, шок, невигідна геометрія або розворот проти обох старших графіків залишаються причиною відмови.

Історична оцінка й її фільтр застосовуються лише до однакових таймфрейму, напрямку, режиму та HTF-контексту, після достатньої незалежної вибірки. Старі результати іншої політики входу збережені, але не навчають нову модель. Детальні формули й встановлення — у `FIXES_AND_INSTALL_UA.md`.

v12.4.1 показує один найкращий новий сценарій: найбільша готовність, при рівності — якість контексту, доступна історична оцінка, відстань. На новий ліміт і повідомлення діє однаковий рейтинг. До двох чинних ордерів супроводжуються незалежно; новий за цикл лише один.

У v12.4.2 ліміт перевіряється від протилежної котировки: LONG < ASK, SHORT > BID. Збіг із ціною останньої угоди допустимий усередині спреду. Цінова модель TP1 до SL на закритій історії зберігається окремо й не надає допуску до входу та не замінює підтверджений win rate.
