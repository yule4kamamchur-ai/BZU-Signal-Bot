# BZU Signal Bot v13.0.1

Це оновлення до v13.0.0. Розпакуйте файли з архіву в репозиторій зі збереженням шляхів і перенесіть видалення з `REMOVE_V13_0_1.txt` у той самий коміт. У вебінтерфейсі GitHub завантажте `main.yml` окремо в папку `.github/workflows`.

Для очищення в локальному Git-клоні збережіть `REMOVE_V13_0_1.txt` поза репозиторієм. З його кореня виконайте команду нижче, підставивши шлях до списку.

```bash
while IFS= read -r path; do
  git rm --ignore-unmatch -- "$path" || break
done < /path/to/REMOVE_V13_0_1.txt
git status --short
```

Список охоплює 47 застарілих інструкцій, звітів, реплеїв, копій та разових скриптів. Копія цього списку в репозиторії для виконання бота зайва. Робочі файли стану й даних беруться з репозиторію. Оновлення містить файли коду й тести.

- У Brent вимкнено старі самостійні OTE, range-compression і momentum-no-pullback. Близькі кандидати з однаковим напрямком і типом виконання об’єднуються. Перші п’ять рядків таблиці сканера враховують близькість між рівнями.
- Для поточних інституційних сетапів скоринг та оцінка лімітки в арбітражі використовують бал `signal_quality`. Перевірки підтвердження входу діють окремо від бала.
- Вихід `CLOSED_ADVERSE_STRUCTURE_SHIFT` потребує 45 хвилин від входу, підтвердженого зустрічного зламу структури M15 і просадки від −0.35R. Заміна завислої позиції починається з 4 годин за власними умовами. Аварійний стоп і ранній аварійний вихід після зустрічного імпульсу мають окремі умови.
