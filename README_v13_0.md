# BZU Signal Bot v13.0.0

Оновлення для репозиторію з версією v12.42. Розпакуйте ZIP і перенесіть файли в однойменні місця в репозиторії одним комітом. Оновіть `.github/workflows/main.yml` у папці `.github/workflows`, а `WORKFLOW_main.yml` у корені. Якщо завантажуєте через вебінтерфейс GitHub, відкрийте папку `.github/workflows` окремо для її файлу.

Архів містить код, інтерфейс, workflow та тести. GitHub Actions використовує існуючі налаштування і журнали репозиторію. Локальна перевірка доступна командою `python bot_oneshot.py --self-test`. Для перевірки браузерної логіки запустіть `node test_live_terminal_ui.cjs`.

## Що змінюється

- У браузері статус сценаріїв і дистанція реагують на котирування OKX. Індикатор дотику або пробою означає спостереження до підтвердження в Python.
- GitHub запускає сканування кожні 5 хвилин за розкладом. Створюється щонайбільше один новий звіт за 15 хвилин. Після помилки доставки черга зберігається для повторної спроби.
- Вхід за M5 враховує лише закрите поглинання біля зони та актуальні bid/ask. Для пробою бази використовується закриття М15 за межею.
- Нові угоди з двома цілями фіксують 50% на +1R. Захисний стоп решти +0.15R набуває чинності з наступної свічки й може підтягуватися за підтвердженими свінгами М15. На дашборді показано, чи захисний стоп уже чинний.
- Відновлення після блокування паперового ордера №199 спрацьовує лише для доведеного дотику до активації. Запис переходить в `UNCONFIRMED` із причиною `TOUCH_BEFORE_ACTIVATION`, без створення виконання чи результату PnL.

Фактичний час запуску залежить від GitHub Actions. Виконання паперове. Короткий реплей перевіряє поведінку коду. Для оцінки результативності потрібна окрема довша вибірка.
