# v12.30 Institutional Pro

1. Розпакуйте компактний ZIP. Завантажте **18 файлів усередині** `01_UPLOAD_TO_REPO_ROOT` у корінь наявного репозиторію. Збережіть коміт.
2. Завантажте `main.yml` з `02_UPLOAD_TO_WORKFLOWS` у **.github/workflows**. Збережіть другий коміт.
3. Запустіть **Actions → Run workflow**. Після успішного **deploy-pages** відкрийте **Settings → Pages → Visit site** й натисніть **⌘Shift+R**.

Компактний пакет призначений для репозиторію зі свіжого архіву v12.29.1. Наступний цикл сформує публічний `live_state.json`. Повний архів містить офлайновий зліпок із часом оригіналу.

Для допуску потрібні структурні TP1 і TP2 |
| Каскад | Підтверджений ретест зламаного рівня M15, зона OTE 61.8–70.5% від останнього завершеного імпульсу, реакція всередині нативної зони та глибший резерв. M5 підтверджує момент входу, коли рівень зламу належить нативній зоні M15/H1/H4 |

Чек-лист містить два інтервали для відкату. Середина зони використовується для раннього сценарію, а для окремої зони OTE вибрано зазначені в ньому **61.8–70.5%**. Обсяг формування понад 1.35 × SMA20, структурний ризик, чисте R:R та правила Б/У після TP1 і закритої M5 застосовуються під час допуску й супроводу.

## Перевірка

- Пройшли 108 штатних Python-тестів, локальні сценарії інтерфейсу та перевірка синтаксису workflow.
- Приклад 99.51 відтворено як тест. Для зони 99.16–99.96 ціна нижча за середину 99.56, тож розраховується внутрішній рівень 99.44. Це синтетичний сценарій із заданим ATR, а не поточний зліпок.
- Свіжий архів містить зліпок **09.11.2026 о 07:31:09 за Києвом** із ціною 96.93. Після офлайнового перерахунку видно 11 оцінених зон. Допущених входів у цьому зліпку немає. Основний довідковий SHORT-рівень 97.29 має пояснення обмеження шляху до цілі.
- Локальний UI перевірено сценаріями з імітацією відповідей на запити M5. Візуальний рендеринг у браузері не перевірено.
